AEROWASH.

Un proyecto de robótica orientado a automatizar la limpieza de superficies mediante drones y sistemas de pulverización.

¿QUÉ ES?

AeroWash no es solo un dron: es un concepto de automatización industrial. La investigación gira alrededor de cómo combinar vuelo, pulverización, sensores, control y software para hacer posible una nueva forma de limpiar grandes superficies. Las cifras mostradas son objetivos de diseño, no resultados garantizados.

CARACTERÍSTICAS

01 / DRONE

Plataforma aérea

Diseño orientado a mover el sistema de limpieza sobre superficies.

02 / CLEANING

Pulverización

Integración de un sistema de agua a presión para realizar la limpieza.

03 / SENSORS

Sensores

Concepto con sensores de distancia y cámaras para conocer el entorno.

04 / CONTROL

Electrónica

Arquitectura basada en controladores y sensores para gestionar el sistema.

05 / AI

IA externa

La parte de inteligencia puede ejecutarse fuera del dron para descargar el hardware.

06 / SCALE

Escalabilidad

El objetivo final es estudiar cómo coordinar múltiples unidades de limpieza.
